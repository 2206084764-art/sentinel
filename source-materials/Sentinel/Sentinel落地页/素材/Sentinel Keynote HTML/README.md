# Sentinel Release Keynote (HTML)

A click-through HTML slide deck for the Sentinel (S5) 24/7 AOV camera launch,
built in the same style as the DS100 keynote deck.

## How to present

Open **`Player点我点我.html`** in a browser (Chrome recommended).

- **← / → keys or click the screen edges** — switch slides (files)
- **Click the center of a slide** — advance that slide's internal animation steps
  (left 30% of the slide steps back, right 70% steps forward)
- **L** — jump-to list · **F** — fullscreen · **Esc** — close list

Each numbered `*.html` file is also a standalone slide you can open directly.
